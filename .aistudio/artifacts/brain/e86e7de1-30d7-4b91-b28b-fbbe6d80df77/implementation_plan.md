## รายละเอียดการเปลี่ยนแปลง (Proposed Changes)

### 1. ฝังบัญชี Super Admin ใน Backend (`server.ts`)
- สร้างตัวแปรคงที่ `HARDCODED_SUPER_ADMINS` บรรจุข้อมูลทั้ง 7 ท่านข้างต้น
- ในฟังก์ชัน `getInitialDatabase()` และ `loadDatabase()`: ลบข้อมูลผู้ใช้เก่าทั้งหมด (STF001, STF002, ฯลฯ) และใช้เฉพาะ 7 ท่านนี้เป็นผู้ใช้งานระบบ
- ใน API `/api/auth/login`: ให้สามารถล็อกอินด้วยเบอร์โทรและรหัสผ่านตรงกับเบอร์โทรศัพท์ของแต่ละท่าน พร้อมตั้งค่าให้มีสิทธิ์ Super Admin เต็มรูปแบบ
- ยกเลิกการซิงก์ตาราง `Staff` ไปยัง Google Sheets (ปรับลดจาก 10 ชีต เหลือ 9 ชีตหลักสำหรับข้อมูลงาน กิจกรรม การจอง ที่นั่ง การเงิน เช็กอิน บันทึกประวัติ และการตั้งค่า)

### 2. ปรับปรุงหน้าต่างล็อกอิน (`StaffLoginModal.tsx`)
- เพิ่มแผงเลือกด่วน (Quick-Select / Quick-Fill) สำหรับ Super Admin ทั้ง 7 ท่าน เพื่อให้สามารถกดเลือกชื่อท่านใดก็ได้เพื่อกรอกเบอร์โทรและรหัสผ่านอัตโนมัติได้ในคลิกเดียว
- รองรับการกรอกเบอร์โทรศัพท์และรหัสผ่านด้วยตนเองสำหรับทุกท่าน

### 3. ปรับปรุงหน้ารายการผู้ใช้งาน (`StaffManagement.tsx`)
- แสดงรายชื่อ Super Admin ทั้ง 7 ท่านอย่างเป็นระเบียบ พร้อมป้ายกำกับ "บัญชีระบบหลัก (System Embedded Account)"
- ล็อกบัญชีทั้ง 7 ท่านไม่ให้สามารถถูกลบออกจากระบบ เพื่อความปลอดภัยสูงสุด

### 4. ปรับปรุงระบบ Google Sheets Sync (`GoogleSheetsSyncModal.tsx`)
- ปรับโครงสร้างแผ่นงานที่ซิงก์ให้ไม่มีชีตผู้ใช้งาน (Staff Sheet) คงเหลือเฉพาะ 9 ชีตข้อมูลหลักตามความต้องการ
